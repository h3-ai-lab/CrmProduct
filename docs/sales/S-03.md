## 操作步骤

1. 入口：销售管理 → 销售中心 → **我的跟进** 页签。
2. 找到客户，点击 **更多 → 更新跟进**。
3. 填写客户反馈、下一步动作、回访时间。
4. 保存后检查时间轴。

## 完成确认

最新备注和最后更新时间已刷新。

## 注意事项

- 备注必须能让下一位同事看懂。
- 「我的跟进」行内「更多」菜单还提供：**试听课报告**、**重新分配线索**（组长）、**添加会员时长**。
- 长时间无跟进记录的线索会被自动掉库（默认领取后 7200 分钟，见 A-02），及时更新跟进就是保住线索的方式。
