## 操作步骤

1. 入口：销售管理 → 销售中心 → **通话记录** 页签。
2. 按用户ID / 姓名 / 登录账号搜索，或按国家、**通话结果**、外呼坐席邮箱、时间范围筛选。
3. 核对：起呼时间、用户ID、姓名、手机号、通话结果、时长、录音、文字稿、本次跟进记录。
4. 已接通的通话可点击 **播放录音**；有文字稿的点击 **下载文字稿**。

## 字段说明

- **通话结果**：已接通 / 无人接听等。
- **录音**：显示「播放录音」或「同步中」（刚挂断的通话录音需要同步时间）。
- **文字稿**：显示「下载文字稿」或「录音暂不可用」。

## 完成确认

能找到目标通话并判断下一步。

## 注意事项

- 刚结束的通话录音可能显示「同步中」，稍后刷新即可。
- 普通销售通常仅可查看自己的通话记录。
