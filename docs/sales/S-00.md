## 页面结构

入口：**销售管理 → 销售中心**。

顶部流程图提示：

> 注册（有手机号）→ 自动分配 / 待领取 → 跟进中 → 付费回流用户中心

页面有四个页签：

| 页签 | 看什么 | 常用操作 |
|---|---|---|
| 公海 | 待领取线索 | 领取跟进 |
| 我的跟进 | 本人当前线索 | 拨号、更新跟进、重新分配、退回公海 |
| 已付费 | 已支付用户 | 拨号、继续跟进续费 |
| 通话记录 | 外呼结果、录音和文字稿 | 播放录音、下载文字稿 |

## 线索怎么流转

1. 已注册、有手机号且未付费的用户进入销售中心。
2. 命中业务线分配权重时直接进入销售的「我的跟进」。
3. 未命中时进入公海，需要人工领取。
4. 领取后超过配置时间无跟进记录，系统可能按规则掉库并重新分配。
5. 超 30 天未付费或手动退回后，线索回到公海，需要再次领取。
6. 付费后用户进入「已付费」页签，但当前仍保留在该销售名下供续费跟进。
7. 系统不支持手工录入手机号；新建线索来源按现有线索接入流程处理。

## 常用筛选

- 手机号 / 用户 ID / 姓名。
- 国家、购买意向、CC、当前跟进阶段。
- 年龄段、课程等级。
- 渠道来源-落地页、渠道来源-App、渠道 code。
- 用户状态、销售咨询预约、预约外呼、注册时间区间。

## 按钮说明

- **重置筛选**：清空当前条件。
- **导入 leads**：批量导入线索，需要对应权限。
- **下载数据**：下载当前筛选范围，需要权限且只用于授权业务用途。
- **分配与掉库设置**：销售人员通常不可见；组长 / 管理员可配置。

## 组长视角

销售组长可查看并重新分配组内、业务线范围内的线索，并在右上角配置分配与掉库规则。普通销售应只处理本人线索。

## 注意

- 购买意向和跟进阶段用于筛选，不等于成交承诺。
- 已付费用户当前仍在销售中心，不能按旧规则认为付费后立即离开。
- 手机号、录音、导入和导出属于敏感能力。
