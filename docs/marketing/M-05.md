## 页面说明（原文）

> 按业务线配置落地页皮肤。可暂时保存草稿后离开；**提交后才发布并生成模板 ID**，落地页管理的「皮肤类型」按业务线选择该模板 ID。

## 操作步骤

1. 入口：营销中心 → **落地页皮肤管理**。
2. 点击 **+ 新建皮肤**，选择业务线与落地页类型（支付落地页 / 获客落地页）。
3. 配置注册方式：手机号注册成账号（有/无验证）、无注册、仅三方登录。
4. 可保存草稿；点击提交后发布并生成模板 ID（如 `KR_SKIN_A`）。
5. 行内操作：**预览**、**编辑**（发布后编辑会生成新版本号 V2/V3…）、**操作记录**。

## 字段说明

| 字段 | 说明 |
|---|---|
| 模板 ID | 发布后生成，落地页管理（M-04）按此选择 |
| 状态 | 已发布 · V版本号 / 草稿（未发布） |
| 注册方式 | 决定落地页上用户的注册行为 |

## 完成确认

皮肤状态为「已发布」且有模板 ID；在落地页管理新建时可选到该模板。

## 注意事项

- 未发布的草稿不会出现在落地页管理的皮肤选项中。
- 每次编辑发布都会产生新版本，历史可通过操作记录追溯。
