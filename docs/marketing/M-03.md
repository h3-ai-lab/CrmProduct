## 配置规则（页面原文）

> 一个渠道仅对应一套关联规则，可编辑现有规则并查看历史。方案内 SKU 不可重复；每个 SKU 可原价售卖、折扣或立减，**优惠后价格不得低于原价的 60%**。

## 操作步骤

1. 入口：营销中心 → **渠道 SKU 价格方案**。
2. 点击 **+ 新建关联**，选择渠道（一个渠道一套规则）。
3. 从已有 SKU（M-02）中选择商品，设置售卖方式：原价售卖 / 折扣 / 立减。
4. 可选配置 **Promo Code**（未配置时显示「无折扣，不生成」）。
5. 设置有效期；编辑现有规则会保留历史记录（行内「历史记录」）。

## 字段说明

| 字段 | 说明 |
|---|---|
| SKU 与售卖规则 | SKU、等级、商品编码、售卖规则、应付金额 |
| Promo Code | 该渠道的优惠码 |
| 有效期 | 关联生效区间 |
| 已绑定落地页 | 该方案下已建的落地页数量 |
| 状态 | 生效中 / 已结束 |

## 完成确认

渠道行显示正确的 SKU 应付金额与有效期；状态为「生效中」。

## 注意事项

- 关联决定落地页（M-04）上可售的商品与价格，改价格前先确认投放中的落地页。
- 优惠下限 60% 是硬约束，配置超出会被拦截。
