## 操作步骤

1. 入口：营销中心 → **SKU 管理**。
2. 按 Product Code / Package Name 搜索，或按业务线、售卖状态筛选。
3. 核对字段：业务线、Package Name、Member Level、商品编码、Payment Mode、原价、有效期、适用端、展示策略、状态。

## 字段说明

- **商品编码** 规律：`web-国家-等级-时长`（如 `web-th-pro-1y` = 泰国 PRO 年卡）。
- **Member Level**：PRO / PRO_MAX。
- **Payment Mode**：ONE_TIME（一次性买断）等。
- **有效期**：1W / 1M / 1Y。
- **展示策略**：推荐 等；**状态**：上架。
- 原价按各国本地货币计价（日本 ¥、新加坡 S$、泰国 ฿、印尼 Rp、马来 RM）。

## 完成确认

能找到目标 SKU 及其原价与有效期，用于后续渠道关联（M-03）与落地页配置（M-04）。

## 注意事项

- 营销中心**不能新增或修改 SKU**，商品调整需走商品系统。
