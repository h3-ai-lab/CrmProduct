## 配置链路

| 步骤 | 手册 | 一句话 |
|---|---|---|
| 1. 渠道 | M-01 | 建渠道，拿系统生成的渠道码 |
| 2. SKU | M-02 | 查商品系统维护的可售 SKU（只读） |
| 3. 渠道 SKU 关联 | M-03 | 一渠道一套规则：卖什么、什么价、什么优惠 |
| 4. 落地页 | M-04 | 获客页挂渠道；支付页挂 SKU，生成 LP ID |
| 5. 皮肤 | M-05 | 页面样式模板，发布后生成模板 ID |

归因与交易链路：**渠道码 → 落地页(LP ID) → 注册/支付 → 订单(O-01) → 线索进销售中心(S-00)**。
