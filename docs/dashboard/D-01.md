## 操作步骤

1. 入口：左侧菜单 → **管理看板**。
2. 选择业务线（如马来）、CC 与注册日期范围；顶部三张卡片分别为：**转化总览**（同一注册批次的六环转化）、**销售跟进**（外呼与跟进情况）、**支付结果**（支付人数、收入与 AOV）。
3. 查看下方「注册批次转化漏斗」：01 线索数（含已付费）→ 02 外呼人数 → 03 接通人数 → 04 预约人数 → 05 体验完成人数 → 06 已支付人数，右侧汇总线索→付费转化率。

## 口径说明（页面原文）

- 注册日期选定同一批线索，后续结果统计至当前。
- 各环节**按用户去重**，同一注册批次可跳过部分环节，人数不强制递减（例如体验完成人数来自课程记录，与销售预约出席分别统计）。

## 完成确认

所选业务线的漏斗与转化率正常展示，与最近外呼节奏对得上。

## 注意事项

- 漏斗是管理员判断卡点的第一入口：预约人数相对接通人数偏低时，优先查外呼时段与话术（见 S-02 / A-04）。
- 看板数据随统计口径更新，对比多日趋势时保持筛选条件一致。
