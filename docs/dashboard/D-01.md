## 页面结构

入口：左侧菜单 → **管理看板**。

页面有三个页签：

| 页签 | 看什么 |
|---|---|
| 转化总览 | 同一注册批次的六环转化和线索→付费转化率 |
| 销售跟进 | 当前线索概况、外呼、预约、跟进和已拒绝 / 已结束原因 |
| 支付结果 | 支付人数、订单数、实付金额、AOV 和币种 |

## 查看转化总览

1. 选择业务线、CC 和注册日期。
2. 查看六个环节：线索数（含已付费）→ 外呼人数 → 接通人数 → 预约人数 → 体验课完成人数 → 已支付人数。
3. 右侧查看 **线索→付费转化率（L2S）** 及其分子、分母。
4. 点击右上角 **统计口径** 查看当前指标定义。

## 读图规则

- 注册日期选出同一批用户，后续结果统计至当前。
- 各环节按用户 ID 去重。
- 同一批次可以跳过部分环节，人数不要求逐级减少。
- 体验课完成人数来自课程记录，不能用销售预约出席替代。
- 支付结果按有效已支付订单统计，不同币种不直接相加。

## 销售跟进怎么用

1. 先看当前线索概况，判断是否有可跟进线索。
2. 再看待外呼、未接通待跟进和待预约。
3. 对比外呼与接通人数，定位线路、时段或话术问题。
4. 查看已拒绝和已结束原因分布，判断客户异议是否需要统一处理。

## 注意

- 页面上的更新时间和日期按当前浏览器的时区展示。
- 对比趋势时保持业务线、CC 和日期口径一致。
- 看板用于判断和核对，不直接修改线索或订单。
