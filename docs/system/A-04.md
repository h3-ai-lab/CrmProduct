## 外呼前确认

1. 账号已经绑定外呼坐席。
2. 线索有可用手机号和正确国家。
3. 电话条已登录，外显方式按国家匹配。
4. 浏览器网络稳定；Omicall 等指定线路需使用可用网络环境。
5. 使用 CRM 行内 **拨号**，不要手工输入号码。

## 常见问题

| 现象 | 优先检查 | 处理 |
|---|---|---|
| 没有拨号按钮 | 线索是否有手机号、账号是否绑定坐席 | 把用户 ID 和账号情况反馈给管理员 |
| 电话条离线 | 坐席账号是否在线、电话条模式是否正确 | 重新登录电话条并选择网页模式 |
| 无法调起呼叫面板 | 当前网络或国家线路 | 切换稳定网络；仍失败时记录时间和国家 |
| 能拨号但接通率异常 | 国家线路、外显号码和时段 | 抽样核对通话记录，向线路负责人反馈 |
| 通话结束但录音同步中 | 第三方录音同步延迟 | 稍后刷新；持续失败时记录通话时间和服务商 |

## 通话结束后

1. 补全购买意向和通话小结并保存。
2. 在「通话记录」确认通话结果、时长、录音和文字稿状态。
3. 未保存小结不算完成一次有效跟进。

## 反馈问题时提供

- 业务线、账号和坐席邮箱。
- 用户 ID 和起呼时间。
- 页面现象、错误提示和外呼服务商。
- 通话结果与录音同步状态。

不要发送完整手机号、录音地址或登录凭证。
