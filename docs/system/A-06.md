## 操作步骤

1. 入口：系统管理 → 系统配置 → **成员账号** 页签。
2. 点击 **+ 新增成员**，填写邮箱与昵称，分配角色和业务线（数据权限随角色）。
3. 对已有成员：按邮箱/昵称搜索，或按角色、状态筛选后点击 **编辑成员** 修改信息。
4. 为呼叫中心坐席点击 **绑定外呼**（已绑定的显示 **管理外呼**），完成电话条账号关联（销售侧使用见 S-02）。
5. 离职或长期不用时，将该成员状态切换为**停用**。

## 完成确认

成员列表中新成员可见、状态与业务线正确；坐席行显示已绑定外呼标记（CC）。

## 注意事项

- 角色决定功能范围，业务线决定数据范围，两者都要分配正确。
- 停用不会删除历史跟进与通话记录；重新启用后数据自动恢复可见。
- 成员的每一次新增/编辑/启停都会进入操作日志（见 A-05）。
