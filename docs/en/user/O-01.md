## Steps

1. Entry: Order Management (订单管理) → **Order Center (订单中心)**.
2. Search supports: Order ID / User ID / Product Name / Promo Code.
3. Filter by country, user type, order status, and payment method.
4. Verify fields: Order ID, Product Name, User ID, Phone Number, Promo Code, User Type, Country, User Status, Order Status, Original Price.
5. Click **Export (导出)** when bulk data is needed.

## Field Reference

- **Order ID** prefixes indicate the source: IDs starting with `PO` are in-app purchases; IDs starting with `WEB` are purchases from web landing pages.
- **Product Name**: plans such as Annual Card / 1 Year / 6 Months.
- **Order status**: pending payment / canceled / paid, etc.

## Completion Check

You can locate the target order and verify its amount and status.

## Notes

- Orders using a promo code display the discount code; the discounted price must not be lower than 60% of the original price (see M-03 configuration rules).
- Orders and the User Center are data-linked: after payment the user status becomes "Paid" and the lead automatically leaves the Sales Center (see S-00).
