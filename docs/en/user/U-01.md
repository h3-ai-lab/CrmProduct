## Steps

1. Entry: User Management (用户管理) → **User List (用户列表)** (page title is "User Center (用户中心)").
2. Search by User ID / Name / Login Account, or filter by user type, registration method, channel source - landing page, channel source - App, country, and user status.
3. To resend a verification code, click the refresh button in the "SMS Verification Code (短信验证码)" column of that row.
4. The row **Actions (操作)** menu provides three options: **Edit Information (修改信息)**, **Add Membership (添加会员)**, and **Edit Trial Lesson Level (修改试听课等级)**.
5. Click **Export (导出)** when bulk data is needed.

## Field Reference

- **User status**: not paid, no trial / not paid, in trial / paid, etc.
- **User type**: registered user (正式用户) / guest user (游客) (guest users have no login account and no row actions).
- **Registration method**: mobile number, etc.; age range and course level (e.g. 6–8, L1/L2) come from user learning data.

## Completion Check

After editing information or adding membership, the list fields refresh immediately.

## Notes

- Customer mobile numbers are sensitive information; handle them with care (see A-03).
- The export function is subject to permission and compliance requirements; exported data is for business use only.
