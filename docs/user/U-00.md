## 手册索引

| 页面 | 手册 | 常用操作 |
|---|---|---|
| 用户管理 → 用户列表 | U-01 | 查找用户、核对短信验证码、修改信息、添加会员、导出 |
| 订单管理 → 订单中心 | O-01 | 查询订单（PO/WEB 前缀）、筛选状态、导出 |

数据联动：用户付费 → 用户状态变「付费」→ 已付费用户当前保留在销售中心供续费跟进（S-00）→ 订单中心可查该笔订单（O-01）。
