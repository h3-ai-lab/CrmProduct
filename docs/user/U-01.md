## 查找用户

入口：**用户管理 → 用户列表**，页面标题为「用户中心」。

1. 输入 **用户 ID / 姓名 / 登录账号** 搜索。
2. 按需选择用户类型、注册方式、渠道来源-落地页、渠道来源-App、国家和用户状态。
3. 点击筛选器后列表立即刷新；点击 **重置筛选** 清除条件。

## 列表怎么读

| 字段 | 用途 |
|---|---|
| 用户 ID | 跨用户、订单和线索核对的主要标识 |
| 用户状态 | 未付费未体验 / 未付费体验中 / 已付费等阶段 |
| 用户类型 | 正式用户 / 游客用户；游客通常没有登录账号和行内操作 |
| 年龄段、课程等级 | 判断销售沟通和课程匹配 |
| 注册方式、登录账号 | 排查登录方式和账号问题 |
| 短信验证码 | 排查用户收不到验证码的登录问题 |
| 渠道来源 | 区分落地页和 App 来源 |
| 操作 | 修改信息、添加会员、修改试听课等级等，按角色显示 |

## 常见任务

**查看短信验证码**

1. 确认用户已完成注册且正在处理该用户的登录问题。
2. 点击该行的短信验证码图标。
3. 只将验证码用于本次登录排查，不转发、不截图、不用于其他账号。

**修改用户信息 / 添加会员 / 修改试听课等级**

1. 点击行内 **操作**。
2. 选择对应操作，核对用户 ID 和修改内容后提交。
3. 成功后列表刷新；需要时到订单中心或操作日志交叉核对。

**导出用户**

点击 **导出**，导出当前筛选范围。导出需要独立权限，超大数据量时先缩小筛选范围。

## 没有操作按钮怎么办

- 游客用户没有登录账号，通常没有行内操作。
- 角色没有对应敏感权限时，按钮不会显示。
- 可以将用户 ID、页面和需要的操作反馈给系统管理员；不要通过复制链接或修改页面参数绕过权限。

## 注意

- 手机号、短信验证码和导出数据都属于敏感信息（见 A-03）。
- 修改信息或会员后，以列表刷新结果和订单 / 会员记录共同确认。
