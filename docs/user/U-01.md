## 操作步骤

1. 入口：用户管理 → **用户列表**（页面标题为「用户中心」）。
2. 按用户ID / 姓名 / 登录账号搜索，或按用户类型、注册方式、渠道来源-落地页、渠道来源-App、国家、用户状态筛选。
3. 需要重发验证码时，点击该行「短信验证码」列的刷新按钮。
4. 行内 **操作** 菜单提供三项：**修改信息**、**添加会员**、**修改试听课等级**。
5. 需要批量数据时点击 **导出**。

## 字段说明

- **用户状态**：未付费未体验 / 未付费体验中 / 付费 等。
- **用户类型**：正式用户 / 游客用户（游客用户无登录账号，无行内操作）。
- **注册方式**：手机号 等；年龄段与课程等级（如 6–8、L1/L2）来自用户学习数据。

## 完成确认

修改信息或添加会员后，列表字段立即刷新。

## 注意事项

- 客户手机号为敏感信息，注意保护（见 A-03）。
- 导出功能受权限与合规要求约束，导出数据仅限业务用途。
